# Домашняя задача

- `GET /tasks` - получение списка всех задач
- `GET /tasks?status=NEW` - получение списка всех задач со статусом `NEW`
- `GET /tasks?status=NEW&priority=HIGH` - получение списка всех задач со статусом `NEW` и с приоритетом `HIGH`
- `GET /tasks?status=NEW&priority=HIGH&assigned=2` - получение списка всех задач со статусом `NEW` и с приоритетом `HIGH` который присвоен 2-ому сотруднику
- `GET /tasks?owner=1` - получение списка всех задач созданный сотрудником с id=1
